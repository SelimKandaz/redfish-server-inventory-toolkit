# Security Policy

## Reporting a security concern

Please open an issue with a clear description of the risk and affected workflow.

For destructive or safety-critical behavior, describe the expected safe behavior and the actual behavior.

## Do not include

- Secrets
- Tokens
- Passwords
- Private operational files
- Generated local reports
- Private screenshots
- Real inventory exports

## Supported posture

This repository is intended for open-source learning, local use and adaptation. Review and test thoroughly before using any workflow in a production environment.
