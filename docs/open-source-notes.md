# Open Source Notes

The desktop configurator code was sanitized for public release.

## Sanitized

- Organization-specific branding generalized
- Real task CSV removed
- Private IPs redacted
- Real passwords removed
- Generated PDFs and Excel outputs excluded

## Do not publish

- Real BMC/iDRAC/iLO IPs
- Real usernames/passwords
- Real service tags
- Real generated configurator reports
